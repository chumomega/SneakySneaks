# SneakySneaks
## Developed by Chuma Okoro


### Description - Sample API for accessing Sneaker database

### Technologies
- Languages - Java, JavaScript
- Frontend Framework - React
- Backend Framework - SpringBoot
- Database - H2 for Testing, Postgres to be integrated soon
- IDE - Eclipse Photon and Visual Studio Code
- Hosting - This will be hosted on Heroku
- API Documentation - Swagger

### How to Run Frontend
1. Navigate to ```sneakysneaksGUI/README.md``` to view instructions on how to run frontend

### How to Run Backend
1. run ```git clone https://github.com/chumomega/SneakySneaks.git``` to clone the repo
2. open project in your IDE
3. right click on the folder in your IDE and run as maven install
4. navigate to the package ```com.example.sneakysneaks``` 
5. run the file ```SneakysneaksApplication.java``` as Java Application
6. Go to web browser and type ```http://localhost:8080/swagger-ui.html#/```
7. Experiment!
